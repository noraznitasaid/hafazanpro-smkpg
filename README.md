# 🎯 Objektif

HafazanPro SMK Pasir Gudang ialah aplikasi Progressive Web App (PWA) yang dibangunkan untuk membantu murid SMK Pasir Gudang menghafaz al-Quran secara sistematik serta memudahkan guru memantau perkembangan hafazan.

---

# ✨ Ciri-ciri

- 📖 Paparan Rasm Uthmani
- 🎧 Audio Mishary Rashid Al-Afasy
- 🔁 Ulangan Audio 1–20 Kali
- 🎤 Rakaman Tasmik
- 👨‍🏫 Dashboard Guru
- 👨‍🎓 Dashboard Murid
- 📊 Kemajuan Hafazan
- 🏆 Leaderboard
- 📱 Android
- 🍎 iPhone
- 💻 Desktop
- 🌐 Progressive Web App
- 📶 Offline Mode
